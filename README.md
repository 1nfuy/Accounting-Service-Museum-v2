## 📖 Описание проекта

Проект представляет собой виртуальный музей, созданный на основе архивных документов Банка России. Сайт разделен на тематические «Залы», каждый из которых посвящен определенной исторической эпохе и аспекту развития бухгалтерской службы.

**Ключевые особенности:**
- 🎨 **Дизайн "Digital Heritage"**: Сочетание эстетики старинных банковских книг (слоновая кость, глубокий изумруд, бордо) с современными цифровыми эффектами (glassmorphism, неоновое золотое свечение).
- 📱 **Mobile-First адаптивность**: Идеальное отображение на смартфонах, планшетах и десктопах.
- ⚡ **Производительность**: Чистый Vanilla JS без тяжелых фреймворков, ленивая загрузка изображений (`loading="lazy"`).
- 🎭 **Интерактивность**: Плавный скролл, анимация появления при скролле (Intersection Observer), интерактивный таймлайн, фильтрация галереи и модальные окна.
- 🎖 **Специальный раздел**: Выделенная карточка и расширенная биография Клавдии Яковлевны Фомичевой — единственной женщины-Героя Советского Союза среди сотрудников Главного банка страны.

```text

    │       ├── helpers.js        # Вспомогательные функции (форматирование валюты)
```

## 🚀 Быстрый старт

Для запуска проекта **не требуется** сборка (Webpack/Vite) или Node.js. Это статический сайт.

1. **Клонируйте репозиторий** или скачайте архив с файлами.
2. **Откройте папку** в редакторе кода (рекомендуется VS Code).
3. **Запустите локальный сервер** (обязательно для корректной загрузки изображений и модулей из-за политики CORS):
   - *Вариант А (VS Code)*: Установите расширение **Live Server** и нажмите "Go Live" в правом нижнем углу.
   - *Вариант Б (Python)*: Откройте терминал в папке проекта и введите `python -m http.server 8000`, затем откройте `http://localhost:8000`.
   - *Вариант В (Node.js)*: Установите `http-server` (`npm i -g http-server`) и запустите `http-server`.

## 📝 Управление контентом

Все текстовые данные вынесены в отдельные JS-файлы в папке `assets/js/data/`. Это позволяет кураторам обновлять музей без правки HTML-разметки.

### Добавление нового руководителя
Откройте `assets/js/data/leaders.js` и добавьте новый объект в массив `leadersData`:
```javascript
{
    id: 17,
    name: 'Имя Фамилия',
    period: '1990–2000',
    role: 'Главный бухгалтер',
    era: 'modern', // 'empire', 'ussr', или 'modern'
    initial: 'Ф', // Первая буква для плейсхолдера портрета
    isHero: false, // Установите true, чтобы применить золотую рамку и расширенное модальное окно
    bio: 'Краткая биография...',
    achievements: 'Ключевые достижения...',
    awards: ['Орден 1', 'Медаль 2']
}
```

### Добавление нового экспоната
Откройте `assets/js/data/exhibits.js`. Чтобы экспонат отображался с фотографией, укажите путь в поле `image`. Если поля `image` нет или оно пустое, автоматически отобразится стилизованная иконка `icon`.

## 🛠 Используемые технологии

- **HTML5**: Семантическая верстка (`<section>`, `<article>`, `<nav>`, `aria-label`).
- **CSS3**: 
  - CSS Variables (кастомные свойства для легкой смены темы).
  - CSS Grid и Flexbox для макетов.
  - `backdrop-filter` для эффекта матового стекла (glassmorphism).
  - `@keyframes` для микро-анимаций.
- **JavaScript (ES6+)**:
  - Модульная архитектура (разбиение на логические файлы).
  - `Intersection Observer API` для производительных анимаций при скролле.
  - Делегирование событий и работа с DOM без jQuery.
- **Шрифты**: *Playfair Display* (для заголовков, атмосфера старины) и *Inter* (для основного текста, современная читаемость) через Google Fonts.

## 🎖 Особые упоминания

- **Клавдия Яковлевна Фомичева**: В проект интегрирована расширенная логика отображения для сотрудников, отмеченных флагом `isHero: true`. Это включает специальную анимацию, боевой таймлайн и цитаты в модальном окне.
- **Калькулятор основных средств**: Интерактивный элемент в "Зале будущего", демонстрирующий преемственность бухгалтерских расчетов от бумажных таблиц к цифровым дашбордам.
